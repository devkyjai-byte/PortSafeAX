전후 비교배정 근거입력과 규칙범위와 한계

기준안은 두 작업자에게 집중 배정한 의도적 불균형 예시입니다. 실제 운영 수준이나 공정한 성능 비교 기준이 아닙니다.

동일 제약의 단순 배정안과 비교

동일한 입력·작업 순서·자격·상한을 적용합니다. 단순안은 ID순 첫 적격자, 재배치안은 배정 후 최대 상한 사용비율이 작은 후보를 선택합니다. 실제 현장 방식이나 최적해를 대표하지 않습니다.

작업자별 누적 부담

회색은 의도적 불균형 기준안, 청록색은 재배치안입니다. 단위는 규칙점수×시간입니다.

작업량 감소에 따른 부담 감소를 안전 개선률로 계산하지 않습니다. 설정 제약 위반0건도 실제 안전을 보증하지 않습니다.

작업별 배정과 후보 검토

작업을 펼치면 해당 작업을 배정하던 시점의 후보별 제약 검사 결과를 확인할 수 있습니다.

관리자는 미배정 사유에 따라 자격 인력 확보·작업 연기·입력 정정을 검토할 수 있습니다. 이 시연에는 승인·정정 이력이나 실제 조치 실행 기능이 없습니다.

입력과 계산 근거

합성 작업자와 시연 상한
합성 작업목록과 작업부담 점수

점수 = 중량지수×0.35 + 반복지수×0.25 + 자세지수×0.25 + 열환경지수×0.15. 모든 입력은0~100 가상지수이며 kg·섭씨가 아닙니다.

추가 부담 = 점수×작업시간. 추가 피로 = 추가 부담×0.12. 피로는 생리 측정값이 아닌 시연 계산상 상태값입니다. 8시간·피로80·부담300 상한은 시연 가정이며 법정·의학적 기준이 아닙니다.

구현 범위와 다음 검증

A 규칙 기반 부담 분석 → B 자격·누적 상태 제약 배정 → C 결과·사유 표시 → E 작업량을 포함한 비교 → F 설치 없는 결과 탐색을 보여줍니다.

필요 자격과 세 상한을 모두 충족하는 후보 중 배정 후 상한 대비 최대 사용 비율이 작은 후보를 선택합니다. 우선순위·점수·작업ID 순으로 처리하며 동률은 작업자ID 순입니다. 탐욕적 방법으로 최적해를 보장하지 않습니다.
