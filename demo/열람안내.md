# PortSafe AX 핵심 작업배정 시연

**시작 위치: `index.html`**. 저장소를 내려받아 압축을 풀고 `demo/index.html`을 여세요. 핵심 작업배정과 별도 접근 경고 연구 시연, 3분 설명 순서, 구현 범위를 확인할 수 있습니다. 각 시연의 ‘시연 시작’ 링크로 돌아옵니다. 세 HTML을 같은 폴더에 유지하세요. GitHub 저장소 파일 화면은 실행 화면이 아닙니다.

실행 앱의 추가 기능: 프로젝트의 `run_demo.bat`로 앱을 연 뒤 **관리자 검토 기록** 탭에서 작업·상태·사유를 입력하고 기록을 추가할 수 있습니다. 이력과 계획을 JSON으로 내려받으세요. 기록은 세션 임시 메모이며 실제 승인이 아닙니다. 미배정 작업은 보류 또는 입력 정정 요청으로만 기록할 수 있습니다. 아래 정적 HTML에는 검토 기록 기능이 없습니다. 최신 전체 자동 검사는39개 통과했습니다.

`PortSafeAX_allocation_demo.html`을 브라우저로 여세요. 파일 하나에 화면과 결과 데이터가 들어 있으며 설치·로그인·외부 라이브러리가 필요하지 않도록 제작했습니다. 실제 제출 전 사용 기기의 브라우저에서 열람을 확인하세요.

1. 기본 작업배정: 배정12건·미배정0건·설정 제약 위반0건 확인.
2. 자격 인력 부족: 배정8건·미배정4건 확인. 미배정 작업을 펼쳐 후보별 자격/누적 상한 검사 확인.
3. 높은 초기 상태값: 배정7건·미배정5건 확인. 미검증 계산상 상태값임을 설명.
4. 입력과 규칙: 작업자·작업 표를 펼쳐 가상지수와 점수 근거 확인.
5. 선택 사례 다운로드: 입력·설정에 필요한 작업자/작업 정보·기준 배정·계산 결과를 JSON으로 보관.

핵심 시연0.2의 **미배정 원인** 메뉴에서는 원인별 작업 수와 자격 충족 후보의 상한 초과 수를 확인합니다. 시드42에서 기본은0건, 자격 인력 부족은 자격 충족 후보 없음4건, 높은 초기 상태값은 자격 충족 후보의 누적 상한 초과5건입니다. 상한별 후보 수는 중복될 수 있습니다. 내려받는 사례 JSON에도 같은 요약을 포함합니다. 최신 로컬 전체 검사는68개 통과했으며 실제 브라우저 화면·클릭 검수는 별도입니다.

전후 비교 아래의 **동일 제약의 단순 배정안과 비교** 표는 같은 작업 순서·자격·누적 상한을 지키면서 ID순 첫 적격자에게 배정한 결과입니다. 두 안의 배정량·위반·부담을 함께 확인하세요. 의도적으로 편중시킨 기존 기준안과 구분합니다.

모든 자료는 합성 데이터이며 학습된 AI가 없습니다. 기존 Python 엔진으로 계산한 결과를 탐색하는 HTML로, 입력 편집·실시간 재계산·관리자 승인·현장 명령 기능은 없습니다. 의도적 불균형 기준안과의 차이를 실제 운영 개선율로 표현하지 않습니다.

카메라·레이더 접근경고 HTML은 별도 연구 자료입니다. 핵심 작업배정 시연과 서로 다른 검증 범위를 갖습니다. SafeBack은 미연동 후속 확장입니다.

검증 상태: 자동 테스트39개 통과. 단순 비교안의300개 합성 조합에서 제약 준수·순서·재현성을 확인했습니다. 시작 화면과 핵심 HTML의 브라우저 직접 열기 검수는 내장 브라우저의 로컬 파일 정책으로 수행하지 못했습니다. 실제 제출 전 화면·상황 전환·후보 펼치기·다운로드를 수동 확인해야 합니다. GitHub에 소스는 업로드했으나 실행 사이트 배포 또는 공모전 접수는 하지 않았습니다.
