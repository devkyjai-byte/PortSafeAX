3분 시연 순서

  1. 0:00–0:30 합성 데이터와 미검증 규칙임을 설명합니다.
  2. 0:30–1:30 작업배정에서 기본 사례와 자격 인력 부족을 비교하고 미배정 사유를 펼칩니다.
  3. 1:30–2:00 동일 제약 비교안의 배정량·위반·부담을 함께 확인합니다. 실제 사고 감소율로 해석하지 않습니다.
  4. 2:00–2:40 접근 경고 시연에서 접근·통과·센서 가림을 비교합니다.
  5. 2:40–3:00 선택 사례 JSON을 내려받고 현장 검증이 필요한 항목을 설명합니다.

접근 경고 연구정확한 상대 위치·속도를 가정한 규칙 판정영상 인식·실제 레이더·장치 경보

관리자 검토 기록은 어떻게 사용하나요?

프로젝트 폴더의 run_demo.bat을 실행한 뒤 ‘관리자 검토 기록’ 탭을 여세요. Windows와 Python 설치가 필요합니다. 작업·상태·사유를 입력하고 계획과 이력을 JSON으로 내려받을 수 있습니다.

세션 임시 메모이며 실제 작업 승인이 아닙니다. 미배정 작업의 ‘검토 확인’은 차단합니다. 새로고침·연결 종료 시 기록이 사라질 수 있습니다.

파일을 내려받아 여는 방법

저장소 전체를 내려받아 압축을 풀고 demo/index.html을 브라우저로 여세요. 세 HTML 파일은 같은 폴더에 두세요. HTML 시연에는 설치·로그인·외부 라이브러리가 필요하지 않도록 구성했습니다.

GitHub 파일 화면은 HTML 소스를 보여줍니다. 저장소 주소 자체가 실행 서비스 주소는 아닙니다. 제출 전 사용할 기기에서 화면·상황 선택·다운로드를 확인해야 합니다.
