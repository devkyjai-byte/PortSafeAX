# PortSafe AX 공모전 MVP 개발 지시안

이 문서는 다음 개발 작업에 바로 사용할 지시안이다. 여기 적힌 신규 기능은 구현 완료가 아니다. 기존 `app.py`, `portsafe/engine.py`, `portsafe/synthetic.py`를 확인해 작성했다.

## 목표와 비협상 원칙

2026-10-29 17:00 KST 내부 제출 목표, 공식 마감10/30 14:00. A/B/C/E/F 중심으로 항만 작업반 배정 검토 장면을 구현하고, 공식 기획서2.1~2.7과 선택자료 안내에 동일한 기능을 연결한다.

1. 이 프로젝트 폴더·환경·데이터·산출물만 사용한다. SmokeFree AI 파일·모델·브랜딩·성과를 가져오지 않는다.
2. 화면·보고서·영상에 `합성 데이터`, `미검증 규칙 계산`, `학습된 AI 모델 없음`, `현장 안전성 미검증` 상태를 표시한다.
3. 규칙점수는 사고확률/의학적 위험도가 아니다. 8시간·피로80·부담300 등은 시연 가정이며 법정·의학적 기준이라고 표현하지 않는다.
4. 자격·시간·피로·부담 상한은 하드 제약이다. 불가능하면 미배정, 우선순위·관리자 승인·AI 출력으로 우회할 수 없다.
5. SafeBack IMU·인솔은 후속 확장만 유지한다. 실제 센서값/연동 완료를 꾸미지 않는다.
6. 현장 자동배치, 실명 작업자 데이터, 자동 제출 기능은 범위 밖이다.

## 구체적 구현 지침

### A: 점수와 예측의 분리

현재 공식은 `0.35×중량지수 + 0.25×반복지수 + 0.25×자세지수 + 0.15×열환경지수`. 0~100 가상지수이며 kg·섭씨 입력이 아니다. 설명 패널에 변수·가중치·시간 누적·한계를 표시한다. 예측 모듈 인터페이스는 `method`, `validation_status`, `data_origin`, `model_version`, `predicted_target`, `uncertainty` 등을 정의하되 미구현 값을 실제 결과처럼 생성하지 않는다.

향후 AI 목표 예: 작업 시작 전 정보로 다음 작업 구간의 독립 평가 부담 지표 예측. 독립 라벨 정의와 측정 신뢰도가 선행되어야 한다. 규칙점수를 정답으로 학습하고 같은 규칙과 높은 일치도를 얻는 방식은 현장 검증이 아니다. 검증 경로: 독립 라벨 확보→작업자/날짜 분리→단순 기준모델 비교→외부 현장 검증→전문가 수용. 충분한 데이터가 없으면 예측 모듈은 미구현 상태를 유지한다.

### B/C: 작업반장의 의사결정 지원

입력→점수 확인→재배치 제안→후보 탈락 이유→미배정 후속조치 선택→검토기록 저장 흐름을 구현한다. 휴식/추가 인력/연기는 제안 문구이며 현재 엔진이 계산하지 않은 회복량이나 일정 변화를 표시하지 않는다. 초기 상한 초과와 새 배정 위반을 분리해, 배정하지 않았다는 이유로 기존 위험을 없어진 것으로 표시하지 않는다.

기존 `audit`는 입력 작업 순서로 감사하고 배정 엔진은 우선순위 순서로 처리한다. 누적량이 단조 증가하는 현재 모델의 최종 상한 검증과 후보 탈락 시점은 구분해야 한다. 감사/설명에서 순서가 달라 사유가 혼동되지 않는지 확인하고, 경로 의존 휴식 모델 도입 시 실행 순서를 명시적으로 보존한다.

### E: 비교를 왜곡하지 않는 결과

비교안별 작업 ID·배정 작업시간·미배정·제약 위반·최대 부담을 제공한다. 기준안은 현재 두 작업자에게 집중시키는 의도적 예시다. 배정량이 다른 경우 단일 “안전 개선율”을 계산하지 않는다. 공통 작업집합 비교도 선택 편향이 있으므로 전체 결과와 함께 보여준다. 향후 추가하는 준수 기준안은 동일 제약을 적용하고 배정 순서·동률 규칙까지 기록한다. 효과는 운영 가설이며 현장 사고 감소를 주장하지 않는다.

### F: 심사 자료

권장 경로는 현재 엔진으로 생성한 세 시나리오 결과를 고정 HTML에 담아 선택·설명·비교가 가능하게 하고, 실제 Streamlit 작동 장면을 3분 영상으로 보완하는 것이다. HTML이 사전 계산 결과만 탐색하면 “사전 계산된 시뮬레이션 결과 탐색”이라고 표시한다. 실시간 재계산 기능이 없는 것을 동적 AI처럼 설명하지 않는다. 외부 CDN·유료 로그인·설치 의존성을 피하고 실제 브라우저에서 한글·표·차트·선택 동작을 검수한다.

영상 구성: 0:00 문제/합성·규칙 고지 → 0:30 정상 배정과 처리량 → 1:15 자격 부족의 미배정 → 2:00 높은 초기 피로 → 2:30 관리자 검토와 향후 AI 검증. 영상 길이는 내부 권고이며 공식 제한이 아니다.

## 검증·인수 기준

- 고정 시드42에서 세 시나리오가 재현되고 입력/결과/버전이 연결된다.
- 신규 배정은 모든 제약을 충족하고, 불가능한 작업을 강제 배정하지 않는다.
- 미배정과 초기 상한 초과가 별도로 보이며 실제 효과/AI 성능 과장이 없다.
- 비교표가 동일 입력·작업량 차이를 설명하고 JSON/화면/기획서 수치가 일치한다.
- 기능 변경에 맞춰 기존 테스트와 의미 있는 신규 경계/비교 검증을 실행한다. 결과·환경·한계를 `VALIDATION.md`에 실제 실행일로 기록한다.
- 비로그인 브라우저·별도 기기에서 제출 자료를 열 수 있고 실행파일·설치가 필요 없다. 이 조건은 아직 검증 완료되지 않았다.
- 기획서 선택자료 안내의 파일명·URL이 정확하고 마감 이후 동일 내용이 유지된다.

범위 축소 순서: 신규 ML → 센서 → 복잡한 스케줄링 → 추가 비교안. 끝까지 유지할 것: 필수서류, 합성/규칙 고지, 안전제약·미배정, 작업량 포함 비교, 접근 가능한 시연, 제출 증거.
