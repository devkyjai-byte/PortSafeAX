# 접근 경고 연구 모듈 — 요구사항·장비선정 기준·실험 기록표

2026-10-20 / 연구 시연0.1. 적용 현장 미정, 구매·현장 승인은 미진행. 기술적 근거와 문헌은 `WEARABLE_SAFETY_FEASIBILITY.md` 참조. 이번 문서는 그 사전검토를 실행 가능한 요구사항과 시험 항목으로 전환한다. 제시된 수치는 설명용 가정이며 안전 기준이나 검증 성능이 아니다.

## 완료한 소프트웨어 시연

- `demo/PortSafeAX_proximity_demo.html`: 설치·로그인·외부 라이브러리 없이 브라우저로 여는 단일 파일. 8개 사전 계산 사례를 선택하는 방식이며 실시간 센서/AI 실행이 아니다.
- 기존 앱의 **접근 경고 연구 시연** 탭: 동일한 Python 규칙으로 합성 사례를 평가한다.
- 계산은 작업자 기준 상대 위치(x=우측,y=전방)와 상대속도(vx,vy)를 정답으로 제공받는 점 표적 모델이다. 현재 위치와 최대6초의 일정 속도 경로가 가정한 반경2m 경계에 진입하는지 판단한다.
- 경계 진입시간은 물리적 충돌시간이나 차량 정지시간이 아니다. 차량 크기·선회·제동·착용자 회전·센서 검출 오차는 미모델링이다.
- 관측이0.5초보다 오래됐거나 장치 상태가 비정상이면 판단 불가로 반환한다. 이 유효시간은 시연 가정이다.
- 방향은 현재 물체의 대략적 몸 기준 방향이며 회피 지시가 아니다. 작업부담 점수나 작업 재배치에 자동 반영하지 않는다.

|사례|합성 입력/의도|예상 시연 결과|
|---|---|---|
|전방 접근|10m 앞, 상대속도 전방축 -2m/s|4초 뒤 경계 진입, 주의|
|후방 접근|6m 뒤, 전방축 +2m/s|2초 뒤 경계 진입, 주의|
|측면 교차|6m 우측, 우측축 -2m/s|2초 뒤 경계 진입, 주의|
|옆으로 통과|우측5m·전방10m, 전방축 -2m/s|최소거리5m, 이 규칙 경고 미충족|
|멀어지는 차량|전방5m, 전방축 +2m/s|이 규칙 경고 미충족|
|가까운 정지 물체|전방1m, 속도0|이미 경계 내, 주의|
|센서 가림|장치 상태 blocked|판단 불가, 위치·경로 표시 억제|
|오래된 관측|관측 경과2초|판단 불가, 위치·경로 표시 억제|

이 시연은 정확한 위치·속도를 안다는 가정 아래 논리를 설명한다. 실제 레이더 도플러에서 곧바로2차원 상대속도를 얻는다는 의미가 아니다. 다중표적 추적·카메라 분류·IMU 보정·센서 가림 감지 알고리즘은 아직 구현하지 않았다. 시연의 blocked 값은 입력으로 지정한 값이다.

## 장비 선정 전 비교 견적 요청 항목

구매는 아직 진행하지 않는다. 아래 조건을 채워 **조끼형과 차량형을 같은 시험으로 비교**한다.

|부품/구성|제조사에 확인할 사양|선정 보류 사유|
|---|---|---|
|레이더 평가모듈1개|국내 사용 조건, FMCW 거리/방향/속도 출력, 최소거리, 실제 FOV, 갱신율, 인터페이스, 타임스탬프, 원자료/트랙 접근, 간섭 진단|목표차량·속도·요구 경고거리 미정|
|카메라|노출/동작 지연, 야간·역광, 셔터/흔들림, 해상도·프레임률, 방수커버, 로컬 영상 접근|촬영 허용범위 미정|
|IMU|동기화, 회전/가속도 범위, 부착 좌표, 드리프트·보정|단독으로 위치/속도 정답 확보 불가|
|처리부|센서 동기처리, 실제 부하 소비전력·발열, 로그, 프로세스 감시|모듈·모델 미정|
|경보기|방향별 진동, 저전압/고장 신호, 장갑/소음환경 인지|착용자 시험 필요|
|기구·전원|분리/세척, 배선 걸림, 총중량, 반사띠 가림, 실제 교대시간 사용|조끼/보호구·교대시간 미정|
|차량형 비교안|장착위치, 차량 전원·운전자 경보, 통신, 운영사 승인|실증 파트너 미확보|

레이더 칩의 최대거리·최저전력·인증 문구만 보고 완제품 성능을 판단하지 않는다. 동일한 커버·부착 각도·펌웨어로 측정한 결과와 최종 제품의 적합성을 확인해야 한다. 장비 공급사 답변을 받았다는 사실과 현장 검증 통과를 구분한다.

## 실험 진행 순서

1. 현장 책임자와 작업 종류·차량 속도·위험 사건·보호구 모델을 정의하고 촬영·시험 허용범위를 확인한다.
2. 단일 센서 벤치시험에서 독립 측정 기준 대비 거리·속도·지연·전력을 기록한다.
3. 마네킹/이동표적과 물리적 분리된 통제 시험장에서 8개 시나리오를 확장한다. 사람을 차량 충돌 경로에 세우지 않는다.
4. 전후2개와4개 레이더를 동일 조건에서 비교한다. 각도·팔/짐 가림·금속 통로·다중 작업자 조건을 분리 보고한다.
5. 실제 작업에는 개입하지 않는 관찰 시험을 운영사 승인 후 진행한다. 안전 조치와 작업반경 제한을 유지한다.
6. 누락·늦은 경고·지속적 오경보·장치 고장 미표시가 해결되지 않으면 해당 조건 적용을 중단한다. 합의된 기준 통과 후에만 다음 단계로 간다.

## 시험 기록표 — 실제 결과는 아직 없음

각 시험마다 아래 양식을 복사해 작성한다. 소프트웨어 합성 결과를 장비 실측란에 기록하지 않는다.

|기록 항목|입력 내용|
|---|---|
|시험ID / 날짜 / 담당자|미작성|
|시험 단계 / SIMULATED 또는 DEVICE|미작성|
|센서 모델·일련번호·펌웨어 / 설정파일 해시|미작성|
|차량/표적 종류·크기·운동 / 독립 정답 측정 방법|미작성|
|부착 위치·각도 / 작업자 모형·자세·가림|미작성|
|광량·노면·비/오염·금속 구조 / 주변 레이더 수|미작성|
|진짜 위험 여부 정의 / 필요한 경고 여유|사전 정의 필요|
|최초 검출 시각·거리 / 경고 출력 시각|미측정|
|미검출 / 늦은 경고 / 비위협 오경보|미측정|
|총 반복횟수·독립 사건수 / 비위협 관찰시간|미측정|
|전력·배터리·발열 / 장치고장 신호|미측정|
|로그·영상 경로 / 개인정보 처리·보관 근거|미작성|
|판정 / 한계 / 수정내용 / 재시험ID|미판정|

오경보는 시간당 횟수와 관찰시간을 함께, 위험 검출은 사건 수와 누락/지연을 함께 보고한다. 서로 다른 조건을 평균내어 특정 사각의 누락을 감추지 않는다. 시험 합격은 그 시험조건에만 유효하며 사고 예방률을 뜻하지 않는다.

## 사용 방법과 제출 범위

`demo/PortSafeAX_proximity_demo.html`을 브라우저로 열고 상황 선택→위치/경로→판단 근거 순서로 설명한다. 자료 다운로드는 합성 JSON이며 실측 증명서가 아니다. 기존 로컬 앱은 `run_demo.bat`으로 실행한다.

단일 HTML은 접근 경고 연구 모듈만 다루므로 기존 A/B/C/E/F 전체를 증명하는 제출 자료를 대체하지 않는다. 공식 기획서에 새 모듈을 포함한다면 연구 단계·가정·미검증 사항과 이 시연의 범위를 일치시켜야 한다. 최종 제출본은 별도 고정 후 해시를 기록하고 공고의 마감 후 수정 금지를 따른다. 현재 파일은 개발 중 버전이며 실제 제출하지 않았다.
