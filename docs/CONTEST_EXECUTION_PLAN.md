# PortSafe AX 심사 대응·제출 체크리스트·10일 실행계획

기준일 2026-10-20. 공식 근거와 문단 ID는 `CONTEST_REQUIREMENTS.md` 참조. 아래 개발·예산·일정은 PortSafe AX 내부 제안이며 주최 측 요구나 보장된 성과가 아니다.

## 1. 제안 방향

응모명 제안: **PortSafe AX — 항만 작업부담 설명과 안전제약 기반 작업 재배치 의사결정 지원**.
대표 Track: **항만 AX**. 항만 배후 물류 작업반의 작업 시작 전 배정 검토를 1차 적용 장면으로 한정한다. 작업반장이 작업목록·자격·근무 상태를 확인하고, 시스템이 부담 계산·배정 후보·미배정 사유를 제시하며, 관리자가 인력 추가·휴식·연기를 검토한다. 현장 관찰을 마친 사실처럼 쓰지 않고 검증할 문제 가설로 표시한다.

핵심 제안은 “예측 AI를 안전제약 엔진에 연결하는 단계적 AX 구조”다. **현재 구현은 미검증 규칙점수와 휴리스틱이며 학습된 AI는 없다.** 규칙점수를 사고확률이나 검증된 작업부담 위험도라고 부르지 않는다. 제약 준수도 시연상한 준수이지 현장 안전 보증이 아니다.

|기능|현재 확인 상태|출품 준비 보완|
|---|---|---|
|A 작업부담 위험 점수/예측|가중합 점수와 누적 피로 계산 구현|화면 명칭을 규칙 기반 작업부담 점수로 유지. 미래 AI 예측 대상·독립 라벨·검증 절차 명시|
|B 안전제약 재배치|자격·시간·피로·부담 검사, 불가능 시 미배정|관리자 검토 상태, 작업별 사유, 초기 상한 초과 별도 표시. 자동 현장 명령 없음|
|C 관리자 대시보드|전후 지표·분포·사유·입력 설명|항만 작업 장면 명확화, 데이터/모델/검증 상태를 상시 노출|
|E 효과 시뮬레이션|편중 합성 기준안과 재배치안 비교|배정량·시간·미배정을 항상 병기. 공통 작업집합 비교와 공정한 추가 기준안 마련|

|적합성 10|해양산업 작업·자격·업무 시스템과 AI 전환의 연결|2.1·2.4, 항만 시나리오와 작업지시/자격대장 연계 설계|일반 인력관리 대시보드로 보이지 않도록 항만 작업·이해관계자 구체화|
|혁신성·창의성 10|기존 수기 검토와 다른 점, 실패 시 처리|2.2, 근거 설명+불가능 배정 차단+미배정 후속조치|세계 최초·특허성 단정 금지. 기존 방식 비교는 현장 확인 전 가설|
|프로토타입 +최대10|문서와 동일한 핵심 기능·사용자 흐름이 실제 구현됐는가|2.3, 선택자료 안내, 고정 HTML/영상/화면|설치·로그인 없이 정상/부족/피로 시나리오 확인. 장식 화면만 제출하지 않음|

최종점수=min(100, 기본평가+가점). 예: 기본 85+가점10=95, 기본95+가점10=100. 가점을 받는다는 보장은 없으며 필수 서류와 실현 가능성·효과성(합계60점)을 우선한다. 발표심사를 전제로 준비하지 않는다. 3분 영상은 선택 프로토타입 증거이고 수상 후 12월 발표는 별도다.

## 3. 성과 측정과 차년도 실증안

현재 근거는 `docs/VALIDATION.md`에 기록된 과거 테스트 결과와 소스 확인이다. 이번 분석에서 테스트를 새로 실행한 것은 아니다. 제출 전 고정본으로 재실행한다.

|지표|정의·수집|표현 제한|
|---|---|---|
|제약 위반 배정 수|독립 감사 함수가 자격·상한 위반으로 판정한 배정 건수|0건이어도 현실 사고위험 0이 아님|
|배정 작업 수/시간·미배정|두 안의 동일 입력·시드·범위로 건수/시간 병기|작업을 덜 배정한 효과를 안전성 개선으로 오인 금지|
|공통 배정 작업 비교|두 안 모두 배정한 작업 ID 집합을 공개하고 해당 작업량의 추가 부담 분포 비교|전체 운영 개선과 구분, 초기 상태·순서 명시|
|검토 소요시간|동일 사례에 대해 수기/지원도구 사용 시간 측정, 반복·학습효과 기록|현장 측정 전 절감률 미기재|
|Q: 배정 검토 누락|필수 자격/상한 확인 누락 건수, 관리자의 수정 사유|전문가 점검 표준 필요|
|C: 검토 인건비·대체인력 비용|검토시간×시간당 비용과 미배정 해소 비용을 별도 계산|입력 단가·시간은 가정이면 가정 표시|
|D: 작업 완료·지연|계획 대비 완료 작업량, 미배정 대기시간|현 MVP에는 시간창·실제 지연 모델 없음. 후속 측정 지표|

2027년 PoC 제안(확정 계약 아님): 1~2월 협력 작업반 1곳 확보·전문가 검토·동의/비식별화·데이터 정의, 3~4월 관리자 판단과 독립 평가 라벨 수집·오프라인 모델 비교, 5월 업무에 개입하지 않는 병행 관찰, 6월 관리자 승인형 제한 시범. 실제 배치 전 시간창·휴식·장비·동시 작업 제약을 추가 검증한다.

필요 역할: 현장 책임자, 안전 전문가, 데이터/모델 개발자, 앱/최적화 개발자. 내부 비용 산정 예시(견적 아님): 개발 2명×3개월×600만원=3,600만원, 전문가 6회×50만원=300만원, 데이터 정리/현장 협업 500만원, 인프라 6개월×20만원=120만원, 소계4,520만원+예비비10%=**4,972만원**. 부가세·기관 간접비·장비 구매 별도, SafeBack 비용 제외. 인건비 단가와 투입률은 협력기관 확인 후 수정한다.

AI 진입 조건: 예측 시점 이전 정보로 정의된 입력, 규칙점수 복사가 아닌 독립 결과 라벨, 작업자·날짜별 분리와 누출 방지, 기준모델 비교, MAE 등 과제 적합 지표·오차구간·하위집단 결과 공개. 합성자료 학습을 하더라도 “합성자료 내 실험”으로만 표기. 현장 외부 검증과 사전 합의 수용기준을 충족하기 전 “검증된 AI” 표기를 하지 않는다. 데이터 미확보·성능 미달이면 모델 도입을 중단하고 규칙 기반 의사결정 지원으로 범위를 유지한다.
