# Phase 1 — 구현 설계

## 범위
사용자 요구 A/B/C/E/F를 로컬 합성 시연으로 구현합니다. 외부 계정·DB·다른 프로젝트 의존성은 없습니다. D 센서는 인터페이스 경계만 유지합니다.

## 데이터 계약
Worker: 고유 ID, 자격 문자열 튜플, 초기 근무시간·피로·누적 부담, 세 상한.
Task: 고유 ID, 필요 자격 1개, 소요시간(0.01~24시간), 4개의 0~100 가상 지수, 우선순위 1~3.
음수·NaN·무한대·중복 ID를 거부합니다. 합성 작업자 ID는 실명과 무관합니다.

## 안전 불변조건
새 배정은 자격 포함, 배정 후 시간 ≤ 상한, 피로 ≤ 상한, 부담 ≤ 상한을 모두 충족해야 합니다. 작업은 최대 한 번 배정합니다. 배정 실패는 미배정으로 반환하고 모든 후보의 실패 사유를 보존합니다. 미배정 시 누적 상태는 변하지 않습니다. 부족 인력이나 높은 우선순위도 제약을 우회하지 않습니다.

## 처리 흐름
고정 시드 생성 → 기준안 감사 → 제약 기반 재배치 → 별도 감사 함수로 재확인 → 완료량·위반 수·상태 비교 → JSON 결과 저장.
기준안 감사는 불안전 배정을 관찰하기 위해 상태에 반영합니다. 이는 안전 배정 엔진과 목적이 다릅니다.

## 수용 기준
세 시나리오 실행 오류 없음, 재배치안의 제약 위반 배정 0건, 동일 입력 동일 출력, 불가능한 작업 미배정, 합성/규칙 표시 상시 노출, 센서 미연동 명시, 실제 안전 효과 주장 없음. 테스트 통과는 이 계약에 한정합니다.
